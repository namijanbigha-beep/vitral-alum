# راهنمای نصب ویترال روی سرور

این راهنما برنامه را روی یک سرور اجاره‌ای نصب می‌کند تا همه با گوشی و از هر جایی واردش شوند.

## ۱. آنچه لازم است

- **یک سرور لینوکسی (VPS)** با Ubuntu 22.04 یا 24.04، حداقل ۲ هسته، ۴ گیگ رم و ۴۰ گیگ دیسک.
  - اگر بات تلگرام را می‌خواهید، سرور باید **خارج از ایران** باشد (مثلاً آلمان یا ترکیه)، چون سرورهای داخل ایران به تلگرام وصل نمی‌شوند.
- **یک دامنه یا زیردامنه**، مثلاً `app.vitral.ir`. در پنل دامنه یک رکورد **A** بسازید که به IP سرور اشاره کند.
- **توکن بات تلگرام** (اختیاری): در تلگرام به `@BotFather` پیام دهید، `/newbot` را بزنید و توکنی را که می‌دهد نگه دارید.

## ۲. وصل شدن به سرور

- در ویندوز: برنامه‌ی **Terminal** یا **PowerShell** را باز کنید.
- در گوشی: برنامه‌ی **Termius** را نصب کنید.

بعد این دستور را بزنید (IP و رمز را شرکت سرور می‌دهد):

```
ssh root@IP-سرور
```

## ۳. آوردن کد روی سرور

**اگر مخزن گیت‌هاب ساخته شده است:**

```
apt update && apt install -y git
git clone https://github.com/namijanbigha-beep/vitral-alum.git vitral
```

**اگر از فایل zip استفاده می‌کنید:** روی کامپیوتر خودتان، در پوشه‌ای که `vitral-code.zip` را دانلود کرده‌اید، بزنید:

```
scp vitral-code.zip root@IP-سرور:
```

سپس روی سرور:

```
apt update && apt install -y unzip
unzip vitral-code.zip -d vitral
```

## ۴. نصب با یک دستور

```
cd vitral
sudo bash ops/setup.sh
```

اسکریپت این‌ها را می‌پرسد: دامنه، توکن بات (می‌توانید خالی بگذارید)، و موبایل، نام و رمز مدیر. بقیه‌ی کارها خودکار است: نصب Docker، ساخت رمزهای امن، گرفتن گواهی HTTPS، راه‌اندازی دیتابیس و پشتیبان‌گیری شبانه.

اولین بار چند دقیقه طول می‌کشد.

## ۵. ورود

در مرورگر گوشی یا کامپیوتر آدرس `https://دامنه-شما` را باز کنید و با موبایل و رمز مدیر وارد شوید. از منوی «بیشتر» کاربران دیگر را بسازید.

برای اتصال تلگرام: «بیشتر › اتصال تلگرام» را باز کنید، کد بگیرید و آن را برای بات بفرستید.

## نکته‌های مهم

- فایل `ops/.env` روی سرور رمزهای برنامه را دارد. **کلید پشتیبان** (`BACKUP_ENCRYPTION_KEY`) داخل همین فایل است. یک نسخه از آن را جای امنی بیرون از سرور نگه دارید؛ بدون این کلید، پشتیبان‌ها باز نمی‌شوند.
- برای به‌روزرسانی: کد تازه را بیاورید و دوباره `sudo bash ops/setup.sh` را بزنید. داده‌ها حفظ می‌شوند.
- دیدن خطاها: `docker compose -f ops/docker-compose.yml logs app --tail 100`
